# sandbox

## Scripts

```bash
# create db (sqlite) and run migrations.
$ npm run migrate

# start the application (dev mode)
$ npm run css:dev
$ npm run server:dev

# build application for production.
$ npm run pkg

# run the tests (using native NodeJS test runner)
$ npm test

# perform linting (using Eslint) and type checking (using TSC)
$ npm run check

# format code (using prettier)
$ npm run fmt
```
